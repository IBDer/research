# IBDer Research / IBDer 研究与信息

这里整理面向 IBD 患者的可追溯研究动态、主题资料和政策信息。内容用于理解信息，不提供诊断或个体化治疗建议。

## 目录

```text
topics/       深度主题
updates/      研究动态
regulatory/   法律、医保与地区政策
methodology/  发布与审核规则
templates/    简短写作模板
```

内容使用 `Draft → Reviewed → Superseded` 状态。`Reviewed` 表示来源、范围和不确定性已被独立复核，不代表临床认可。

开始写作前请使用 [`templates/`](templates/) 中的最小模板，并完成[发布检查](templates/publish-checklist.md)。
