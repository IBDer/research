# Research catalog / 调研目录

`research.yml` is the machine-readable index of IBDer research publications. It is deliberately small in the first version so it can evolve with real publications and external integration requirements.

`research.yml` 是 IBDer 调研成果的机器可读索引。第一版刻意保持精简，以便根据真实发布内容和外部集成需求持续演进。

Each future item should provide at least:

- stable `id` and version;
- Chinese and English titles;
- publication status;
- document path or canonical URL;
- last search date;
- languages and evidence types;
- authors, reviewers, and license;
- supersession links when applicable.

后续每个条目至少应包含：稳定的 `id` 和版本、中英文标题、发布状态、文档路径或规范链接、最后检索日期、语言和证据类型、作者与审阅者、许可证，以及适用时的版本替代关系。
