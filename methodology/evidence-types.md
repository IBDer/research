# Evidence Types / 证据类型

IBDer uses descriptive evidence labels so readers can see what kind of support exists without mistaking a single score for certainty.

IBDer 使用描述性证据标签，让读者了解支撑某一观点的证据类型，同时避免把单一分数误解为确定性。

| Label | 中文 | Use |
| --- | --- | --- |
| `guideline-consensus` | 指南或共识 | A recommendation or consensus statement from an identified body |
| `systematic-review` | 系统综述 | A documented synthesis using explicit search and selection methods |
| `randomized-study` | 随机研究 | A randomized controlled study |
| `observational-study` | 观察性研究 | Cohort, case-control, cross-sectional, registry, or similar evidence |
| `preclinical-mechanistic` | 临床前或机制研究 | Laboratory, animal, computational, or mechanistic evidence |
| `expert-opinion` | 专家意见 | Interpretation not supported by a documented systematic method |
| `patient-experience` | 患者经验 | Lived experience, survey narrative, interview, or community report |
| `unknown-unverified` | 未知或未核实 | Source or claim not yet verified |

Labels describe source type, not truth, importance, or applicability. Study quality, population relevance, consistency, effect size, uncertainty, and conflicts of interest must still be discussed in the publication.

标签描述的是来源类型，而不代表真实性、重要性或适用性。每份调研仍需讨论研究质量、人群适用性、一致性、效应大小、不确定性和利益冲突。
