# 发布与审核规则

## 内容状态

- `Draft`：尚未独立复核。
- `Reviewed`：至少一名独立审阅者核对了来源、范围和不确定性。
- `Superseded`：已被新内容替代，并链接到新版本。

## 表述方式

- **官方明确**：可定位到官方文件或条款。
- **社区说明**：对来源内容的通俗改写。
- **需要确认**：来源没有写清或实际执行可能不同。

不得用“通常可以”“大概率符合”等无依据表述替代核验。

## 政策时效

政策页面必须标注最后核验日期。地区政策至少每月检查一次；发生重大政策或安全变化时及时更新。超过计划复核日期的内容应标为待确认，旧版本保留并标记 `Superseded`。

涉及临床或法律高风险解释时，应在发布前获得适当的专业复核。
